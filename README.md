# DMZ Config

VSCode Extension for easy editting of Dragon Mine Z config files.

## Features

Snippets for creating custom forms and form groups, all wish types and more planned in the future!

![Form Snippet Preview](assets/preview1.mp4)


## Known Issues

The item wishes dont give you the full list of minecraft/dragonminez items. They also dont add extra fields for the different itemTypes (enchantments, potion, material, trim etc.)
